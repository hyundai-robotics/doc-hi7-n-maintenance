# 개요
- **안전 입출력 신호**는 긴급정지(E-Stop), 안전 도어, 라이트 커튼 그리고 Safety PLC 등과 연동하여 안전 신호를 제어/모니터링하는 전용 장치입니다.
- 국제 안전 표준(EN ISO 13849-1, IEC 61508, IEC 62061 등)에 부합하며, 안전 기능 SIL3/PLe까지 지원합니다.

# 제공 사양

## 1. 기본 안전 입/출력
- 입력 4채널 (Dual 채널)
- 출력 1채널 (Dual 채널)

## 2. 부가 안전 입/출력
- 입력 8채널 (Dual 채널)
- 출력 8채널 (Dual 채널)
