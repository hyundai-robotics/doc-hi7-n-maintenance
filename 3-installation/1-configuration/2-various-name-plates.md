{% hint style="warning" %}
任何损坏安全标签的行为，例如移动名称牌、警告标记、安全符号、名称标记和电线标记，或在其上涂漆或用覆盖物遮挡，都是禁止的。
{% endhint %}

{% hint style="info" %}
以使机器人安装和危险区域在类型、颜色和样式上与其他设施和设备区别开来进行标记。
{% endhint %}
