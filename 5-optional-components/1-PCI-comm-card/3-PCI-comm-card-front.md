# 5.1.3. PCI通信卡的前面部分

您可以通过PCI通信卡的前面部分检查通信设置、通信电缆连接和通信状态。基本上，您可以通过根据H6COM-T PCI插槽的位置将旋转开关按顺序设置为1-4来使用该卡。
