# 5.5.2.3 컨베이어 동기화 구성
다음의 그림은 컨베이어 동기화를 위한 엔코더 입력 및 리밋 스위치로 구성 되어 있습니다.<br>
총 2개의 입력 채널로 구성되어 있으며, 입력 채널의 구성은 다음과 같습니다.
각 채널 당, 2종류의 엔코더 타입(오픈컬렉터/라인드라이버)으로 설정 되어 있습니다.<br>
