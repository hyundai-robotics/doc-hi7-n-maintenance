# 5.5.2 硬件信息
用户 IO 模块 (BD681) 允许通过数字输入/输出端口与各种设备进行连接和配置。  
此外，扩展 IO 模块 (BD682) 允许添加数字 I/O 端口并与传送带系统同步。<br>
板的基本硬件配置如下：

![](../../_assets/그림_5_31_BD681_BD682_HW_및_커넥터_정보_en.png)<br>

### 5.5.2.3 传送带
