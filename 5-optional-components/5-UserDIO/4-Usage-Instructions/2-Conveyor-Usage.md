# 5.5.4.2 컨베이어 엔코더 인터페이스 사용 방법

BD681, BD682의 컨베이어 엔코더 인터페이스를 사용하기 위해서는 우선 "[하드웨어 정보](../2-HW-Inform.md)" 매뉴얼을 참고하여 BD682의 커넥터에 올바르게 엔코더 배선을 연결합니다. 
<br>그리고 연동하기 위한 방법은 아래 내용들을 참고하시기 바랍니다.

<br>

<mark style="color:green;">**- 제어기와 컨베이어 엔코더 연동**</mark>

보드를 이용한 제어기와 컨베이어 엔코더 연동에 대한 세부 내용은 "[센서 동기](https://hrbook-hrc.web.app/#/view/doc-sensor-sync/korean/README)" 매뉴얼의 컨베이어 관련 부분을 참고하시기 바랍니다.
