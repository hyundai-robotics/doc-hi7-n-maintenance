# 5.5.1 概述

在 Hi7 中，'用户 DIO 板 (BD681)' 和 '扩展 DIO 板 (BD682)' 可用于处理通用 I/O 信号并同步输送机编码器。

{% hint style="info" %}
在本手册中，DIO 指数字输入和输出。
{% endhint %}

'扩展 DIO 板 (BD682)' 不能独立使用，应与 '用户 DIO 板 (BD681)' 一起使用。
