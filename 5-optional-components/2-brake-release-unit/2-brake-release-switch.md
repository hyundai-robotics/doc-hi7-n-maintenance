# 5.2.2. 刹车释放开关

刹车释放单元开关的放置如图5.3所示，其各自的使用和操作在表5-4中描述。要释放目标轴的刹车，首先按下启用按钮，然后在按住启用按钮的同时，按下B1-B8中的一个按钮。然后，相关轴将被释放。
