# 5.2.3. 电源和连接器 

刹车释放单元的电源和连接器的放置如下图5.4所示，其各自的使用和连接设备如下表5-5所示。

{% hint style="info" %}
- 使用刹车释放单元时，请遵循以下步骤。
1. 关闭AC220V电源开关，并检查DC24V电源开关是否关闭。
2. 将交流电源电缆连接到交流电源连接器。
3. 打开AC220V电源开关。
4. 打开DC24V电源开关。

- 使用刹车释放单元结束后，请遵循以下步骤。
1. 关闭DC24V电源开关。
2. 关闭AC220V电源开关。
4. 拔掉交流电源电缆。

- 请勿同时使用AC220V电源和DC24V电池电源。
{% endhint %}
