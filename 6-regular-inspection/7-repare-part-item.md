# 6.7. 维护零件

各个零件的特性如下所述。

A类维护零件

{% hint style="info" %}
这些是日常维护和检查时需要准备的重要零件。
{% endhint %}


为了保持正常运作，A-2类和A-3类零件是最低必要的零件，每个组至少应准备一套。
