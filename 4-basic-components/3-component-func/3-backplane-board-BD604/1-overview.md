# 4.3.3.1. 개요

백플레인보드(BD604)는 그림 4.50과 같은 구조로서 Hi7 제어기 보드류릐 제어전원을 공급하고 BD642에서 출력되는 AMP 관련 신호들을 AMP Interface Baord(BD652/Bd654)로 통하여 전달한다. 주요 옵션보드의 고정, 신호 전달 역할을 수행한다.
